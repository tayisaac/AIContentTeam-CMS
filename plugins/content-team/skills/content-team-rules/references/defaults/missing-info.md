# What to do when information is missing

| Missing in project.md | Behaviour |
| --- | --- |
| Voice | Infer from learned/voice-notes.md (or existing copy); state the assumption in the brief |
| SEO | Use defaults/seo.md |
| Audiences / goal | Ask once in the brief; if no answer, infer from existing pages and state it |
| Must-follow (claims, disclaimers) | Reviewer flags EVERY claim, price, percentage or health statement for human review; never passes them automatically |
| Approvals | Treat the requester as the only approver; still never publish |
| CMS writable folders | CMS Operator STOPS and asks. Never guesses where to write |
| Content model / patterns not yet generated | Run "set up this project" first |
