# Default SEO rules

- SEO title: max 60 characters, primary keyword near the start, "| <Brand>" at the end
- Meta description: 140–160 characters, includes the primary keyword and a reason to click
- Slug: lowercase, hyphenated, max ~5 words, no dates unless the page is time-bound
- Exactly one H1 per page (normally the hero headline)
- Headings in order (H2 then H3), no skipped levels
- Primary keyword in the H1 and the first 100 words
- At least 2 internal links to relevant existing pages; link text describes the destination
- Never reuse an existing page's SEO title or primary keyword
