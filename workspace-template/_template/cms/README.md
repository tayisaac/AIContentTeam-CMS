# cms/

The only CMS-specific part of the project. Generated by the Component Librarian, reviewed by you
(ideally with a developer).

- component-catalogue.md  every available component, its fields and rules
                          (format: content-team plugin: skills/content-team-rules/references/formats/component-catalogue.format.md)
- cms-mapping.md          neutral page types and sections -> CMS components and fields
                          (format: content-team plugin: skills/content-team-rules/references/formats/cms-mapping.format.md)

Swapping CMS = connect the new CMS and rerun "set up this project" to regenerate this folder.
